## Building research template

- Stable slug; canonical name; aliases; exact monument boundary.
- Site/locality; district/state; coordinates if verified.
- Primary building type; construction date/range and precision; sourced historical context.
- Styles with evidence and any disputed classification.
- Materials with usage notes and supporting citations; do not infer stone type from colour.
- Elements with location/function, evidence, and optional close-up photographs.
- Layout description, overview, and architectural significance written in original wording.
- Source title, publisher/author, URL, accessed date, page/section, and claim supported.
- Research status: candidate, in progress, verified, or unresolved.

## Media manifest template

Record building slug, optional element identifier, file page URL, original download URL, creator, licence identifier/version, licence URL, original pixel dimensions, byte size, caption, alt text, modification note, local path, display variants, intended role, and review status.

Review gates: correct monument -> explicit reuse terms -> sufficient dimensions -> visual sharpness/composition -> accurate caption -> credit displayed. Do not approve an image purely because it has a large MB count. Final selection and downloading occur during the five-building pilot.
